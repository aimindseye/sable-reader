# Roadmap

1. **Foundation** (this step): licence, documentation and security scans.
2. **Port**: bring the Reader from SableOS 2.0 (library keys, the Bold setting, comic, audiobook and PDF support) and add build, test and lint CI.
3. **Device profiles**: Zinwa Q25, Unihertz Titan 2 and Titan 2 Elite, then Zinwa P26 and Q27.
4. **Themes**: the e-ink theme is gone, so check every phone theme on every screen and recommend a reading background.
5. **Setup wizard**: first-run choice of device profile, theme, text size and library folder.
6. **Stock-firmware polish**: no dependence on the Sable launcher or Active Frames.
